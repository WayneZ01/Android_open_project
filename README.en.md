Android Open Project was created in 2017 to help developers discover reusable Android libraries and examples. It now contains more than 900 curated links across over 80 topics. The catalog preserves historically useful resources while maintaining dedicated sections for Jetpack Compose, Kotlin Multiplatform, on-device AI, testing, performance, security, accessibility, and release engineering.

The full catalog and resource descriptions are maintained in Chinese in [README.md](README.md).

## Why this project exists

- Make Android open-source discovery easier for Chinese-speaking developers.
- Preserve useful knowledge for maintaining legacy Android applications.
- Highlight current, production-oriented tools instead of only collecting links.
- Keep the catalog auditable through automated structure and link-health checks.
- Provide a public workflow for recommendations, corrections, migrations, and archival.

## Project health

- Catalog structure is checked on every relevant pull request and push.
- External links are checked weekly and on documentation pull requests.
- Confirmed dead links are moved to [the archive](docs/archived-links.md), not silently discarded.
- Maintenance decisions and recurring tasks are documented in the [maintainer playbook](docs/MAINTENANCE.md).
- Planned work is tracked in the public [roadmap](ROADMAP.md).
