# Support

This repository is a catalog, so it cannot provide technical support for every linked project.

- For installation, API, bug, or release questions about a listed project, use that project's own documentation and issue tracker.
- To report a dead, migrated, misleading, or unsafe catalog link, use the repository's broken-link issue form.
- To recommend a resource, use the resource-recommendation issue form.
- For changes to this repository, open a focused issue or pull request after reading `CONTRIBUTING.md`.
- For sensitive security concerns, follow `SECURITY.md` instead of posting details publicly.
